# Project Statement

## Problem Statement

Manual resume screening can take significant time when resumes need to be reviewed for relevant skills and suitable job roles.

This project develops an AI-powered resume screening system that automatically extracts information from a PDF resume, analyzes technical skills, calculates a resume score, and recommends a suitable job role using Machine Learning techniques.

## Scope of the Project

The project focuses on automated resume analysis using text processing and Machine Learning techniques. It accepts PDF resumes and provides skill analysis, resume scoring, job-role recommendation, improvement suggestions, and a downloadable analysis report.

## Target Users

- Students
- Job seekers
- Placement preparation users
- Recruiters for basic resume screening

## High-Level Features

1. PDF resume upload and text extraction
2. Technical skill identification
3. Matched and missing skill analysis
4. Resume score calculation
5. Machine Learning-based job-role recommendation
6. Resume improvement suggestions
7. Analysis report generation
